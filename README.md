# Friday 13 November 2026 front page

A newspaper-style summary of 30 reported stories from six continents, drawn as an original 1024×1024 newsprint illustration.

Run the copier with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

To regenerate the image, run `python3 draw_news.py` (requires Pillow).
